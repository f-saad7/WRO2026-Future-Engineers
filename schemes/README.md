# Schemes

Put wiring diagrams and electromechanical schematics here (PNG/JPG/PDF), showing how all components are connected:

- Raspberry Pi 5 GPIO connections
- L298N motor driver wiring (TT motor + battery)
- LM2596 power distribution (battery → 5 V rail)
- I2C bus: TCA9548A → VL53L0X sensors, MPU-9250
- D500 LiDAR and camera connections (USB/UART)
- MG90S servo signal and power
